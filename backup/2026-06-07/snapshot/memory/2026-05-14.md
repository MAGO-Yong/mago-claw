### ~/.zshrc 最终配置（15:04 确认）
```bash
# Claude CLI default permission mode
alias claude="claude --permission-mode acceptEdits"

# Claude proxy with obs-token dashboard push
alias proxy='cd ~/Documents/New\ project/claude-proxy && ./target/release/claude-proxy --obs-token-url http://10.40.49.142:8090'

# Claude proxy 环境变量
export ANTHROPIC_BASE_URL="http://127.0.0.1:8089"
export ANTHROPIC_API_KEY="dummy"

# 打开终端自动检查并启动 claude-proxy（健壮版）
_proxy_pid=$(lsof -ti :8089 -sTCP:LISTEN 2>/dev/null)
if [ -n "$_proxy_pid" ]; then
    if ! ps -p $_proxy_pid -o comm= 2>/dev/null | grep -q claude-proxy; then
        kill -9 $_proxy_pid 2>/dev/null
        cd ~/Documents/New\ project/claude-proxy && ./target/release/claude-proxy --obs-token-url http://10.40.49.142:8090 &>> ~/.claude-proxy/proxy.log & cd - > /dev/null
    fi
else
    cd ~/Documents/New\ project/claude-proxy && ./target/release/claude-proxy --obs-token-url http://10.40.49.142:8090 &>> ~/.claude-proxy/proxy.log & cd - > /dev/null
fi
unset _proxy_pid
```

### 今天遇到的问题
1. **proxy 重复起**：`source ~/.zshrc` 时自动启动逻辑 + 手动 `proxy &` 同时跑，端口冲突（`Address already in use`）
2. **环境变量有 8090 残留**：历史配置写错了 `ANTHROPIC_BASE_URL=http://127.0.0.1:8090`，导致 Claude Code 连错端口
3. **Claude Code 走个人账号**：Claude Code 本地存有 credentials，优先级高于环境变量，需要在 Claude Code 里执行 `/logout` 退出才能强制走 proxy
4. **source zshrc 会 kill proxy**：健壮版逻辑在 source 时会检查端口，可能误 kill 正在运行的 proxy

### 未解决（16:08 截止）
