## 3. 🆕 新发现/新知识

### 🔧 Hi CLI 没有发私信的命令
- `hi im` 只有 `im:upload`（上传文件到 IM 服务，返回 fileId/fileUrl），没有发送消息到指定用户的子命令
- `hi search:chat` 只能搜群聊，`hi search:message` 只能搜消息
- `hi openapi:call-api` 理论上可调用发消息 API，但需要 provider-ids，实际使用门槛高
- **结论**：要从 Agent 容器内发 Hi 私信，只能走 OpenClaw `message` 工具，不能用 hi CLI

### 🐛 message 工具 target=mahengyang 路由到了群聊
- `message(action=send, channel=hi, target=mahengyang)` 返回成功，但实际出现在 `hi:g-mahengyang` 群聊中
- 推测：mahengyang 被解析为群聊 ID 而非用户个人会话
- **影响**：所有通过 `message` 工具发 Hi 私信的场景都需要重新验证 target 格式

## 5. ⚠️ 教训/问题

### 教训：message 工具返回成功 ≠ 消息真正送达

- **改进**：发 Hi 消息后应检查 messageId 是否非空，空串说明投递可能有问题
- **根因待查**：target 格式问题（需要邮箱格式？账号 ID？）
