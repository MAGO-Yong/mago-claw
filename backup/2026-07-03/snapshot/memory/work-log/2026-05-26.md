#### 🟢 确立「dependency_gaps」设计模式

**核心思想**：不可用的能力不阻塞 Skill 上线，在输出中显式标注缺口 + 原因 + 人工操作链接。

```json
{
  "dependency_gaps": [
    {"name": "RPC拓扑指标", "reason": "中间件版本不满足", "manual_url": "..."},
    {"name": "变更查询", "reason": "xray-cli 暂无原子能力", "manual_url": "..."}
  ],
  "conclusion": "auto_cleared | error_found | dependency_gap_required"
}
```

**影响**：推广到所有业务线 Skill 的开发策略——**先跑最小可用形态，能力缺口标清楚，不成为不交付的理由**。
