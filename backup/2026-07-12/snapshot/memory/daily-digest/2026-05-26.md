**完整诊断链路**：

- CPU/Pod：稳定，排除基础设施异常

**意义**：这是 XRay 诊断 Skill 首次在真实告警上完成端到端根因定位。诊断结果准确、完整、可操作。

- **规则**：容器环境的 CLI 认证必须在容器内完成

### 新增 Skill 设计模式：dependency_gaps
```json
{
  "dependency_gaps": [
    {"name": "RPC拓扑指标", "reason": "中间件版本不满足", "manual_url": "..."},
    {"name": "变更查询", "reason": "xray-cli 暂无原子能力", "manual_url": "..."}
```
