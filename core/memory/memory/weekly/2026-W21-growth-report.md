## 🧬 我学到了什么

### 认知升级

1. **SOP→Skill 转化管道验证成功，但「最后一公里」是关键瓶颈**
   - 框架确认到落 Skill 的转化需要用户在线配合（追问细节、确认图表/指标）
   - 用户不在时，Agent 无法自主完成（因为缺少业务上下文和判断标准）
   - **新认知**：SOP 萃取不是单次会话能完成的事，需要「框架确认会话 → 细节追问会话 → 落 Skill 会话」至少 3 轮

2. **M2 窗口滑点模式：方向确认→执行加速→冷却→M2 关闭**
   - W20（5/11-5/17）：假期归来，密集执行（Prototype/前端升级/需求管理）
   - W21（5/18-5/24）：前半周有突破（PR 页面/SOP 萃取），后半周 4 天零交互
   - **规律**：用户上线→高产出→冷却→M2 到期→M3 重新排优先级
   - 这是 M1→M2 滑点的延续（M1 14 天窗口实际执行仅 9 天工作日）

3. **真实告警链接 = 最高效的 Skill 创建入口**
   - 用户直接丢告警链接 `194554127` → Agent 提取服务名/异常类型/触发条件 → 用户补充 SOP
   - 比「帮我建一个告警诊断 Skill」抽象指令效率高 10 倍+
   - 隐性知识显性化的最优路径：真实事件 → 结构化提取 → SOP 建模

4. **产品叙事能力验证：用户一句话定性 > Agent 多轮迭代**
   - 用户原话「我们就是产品宣发，写已经支持的就好了」直接砍掉一半内容
   - 用户原话「重点不只是查询，重点要表达认领、静默等操作」一句话扭转核心叙事
   - **规律**：用户在产品定位判断上极其敏锐，但需要 Agent 先提供足够多的「错版本」才能触发定性

### 规则新增

#### 宣发页面写作三原则（2026-05-18/20 确立）
1. **只写已上线能力**：宣发页面 ≠ 产品路线图，砍掉 Phase 2/3 规划、愿景区块、未上线案例
2. **核心叙事是操作不是查询**：认领、静默等操作能力才是卖点，查询只是入口
3. **部署方式一句话带过**：「一份 Skill，多种入口」即可，不需要三个卡片展开

#### SOP 萃取：真实告警链接驱动（2026-05-20 确立）
- 用真实告警事件链接作为 Skill 创建素材，比凭空描述更准确、更高效
- 告警自带完整上下文（服务名、异常类型、触发条件、持续时间），Agent 可直接提取 Scene Card

#### SOP→Skill 需要多轮会话（2026-05-21 确立）
- 框架确认 → 细节追问 → 落 Skill，至少 3 轮会话
- 框架确认可以在单次会话完成（如 searchadstrigger 6 步链）
- 但细节追问（每个维度的具体排查逻辑/图表/判定标准）需要额外会话
- 落 Skill 需要用户确认最终方案

```
W20（5/11-5/17）：假期归来 → 密集执行（Prototype/前端升级/需求管理）
  ↓ 高热
W21 前半（5/18-5/20）：PR 页面交付 + SOP 萃取启动（3 个框架确认）
  ↓ 冷却
W21 后半（5/21-5/24）：连续 4 天零交互 → M2 实质关闭
```

**M2 最终状态**：
- KR1 通用 Skill 开发 → 🟢 基本完成（评估框架/CLI 分层/diagnosis-skill-builder V1）
- KR2 告警中心诊断闭环 → 🟡 部分完成（Prototype/PR 页面/SOP 框架确认，但 SOP 未落地）
- KR3 业务线 Skill 接入 → 🔴 未达成（0 个正式 Skill 安装到业务线）
- KR4 诊断有效性基线 → 🔴 未涉及

**教训**：M1/M2 两个窗口都出现「前半周高产出、后半周冷却」模式，M3 排期需要：
- 在前 3 天完成最高杠杆交付（searchadstrigger SOP 落地）
- 把需要用户配合的任务排在工作日前半段
- SOP 萃取明确拆分为 3 个独立里程碑（框架/细节/落地），每步独立验收

### 2. 三个 SOP 框架质量极高，是 KR3 破局的关键资产

| SOP | 颗粒度 | 落 Skill 预估时间 | 优先级 |
|-----|--------|------------------|--------|
| searchadstrigger 6 步链 | 最高（数据源/PQL/阈值/分支/输出俱全） | 1-2 小时 | P0 首选 |
| RPC 异常 3 层框架 | 中（框架已定，细节待追问） | 2-3 小时 | P1 |
| 广告收入 5 维度链 | 低（仅维度顺序，排查逻辑未确认） | 3-4 小时 | P2 |

**关键**：searchadstrigger 素材最完整，是 M3 开局的最好切入点。1-2 小时交付一个正式 Skill，能给 M3 开个好头，也验证 SOP→Skill 管道全流程。

### 3. 诊断 Skill 创建器的生态决策窗口

- `diagnosis-skill-builder V1`（22 文件，通用，支持三平台）vs `biz-diagnosis-creator`（用户之前创建，特定场景）
- 两者功能重叠，但 V1 更通用、支持多 Agent 平台
- **决策建议**：保留 V1 作为主创建器，biz-diagnosis-creator 作为历史参考或特定场景快捷入口
