# Diagnosis Skill Builder V1

Version: 1.0.0

V1 scope:

- Generic guided creation flow for diagnosis Skills.
- Scene Card, SOP flow modeling, node evidence binding, dependency preflight, full SOP confirmation canvas, report contract, package draft, single execution check, trial-run plan, and admission placeholder.
- OpenClaw / CC / Codex portability rules.
- No bundled business-specific case, simulation, screenshot, or user-provided SOP content.

V1 boundary:

- Installing Builder does not install all platform dependencies.
- Heavy real-data verification belongs to trial run unless explicitly requested during creation.
- Skill Evaluator / admission remains a placeholder gate.
