
## 项目管理关键节点 SOP

```
规划 → 立项会 → KO会 → 第一次周会 → 例行周会 → 阶段复盘 → 结项会 → 资产清退
```

| 阶段 | 关键输出 |
|------|---------|
| 启动期 | KO材料、立项会、KO会 |
| 执行期 | 会议体系、周报文档（持续更新） |
| 收尾期 | 复盘文档、资产清退计划 |
