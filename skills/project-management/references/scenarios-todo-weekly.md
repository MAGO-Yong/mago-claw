# 场景参考：Todo 完成情况 & 例会文档更新

## 场景1：查看项目 Todo 完成情况

```bash
pmo todo "<项目名>"
```

pmo 内部封装完整流程：获取项目配置 → 找最新周会文档 → 识别 Todo/待办表格 → 格式化输出。

**发送催更通知（用户要求时）：**

```bash
pmo send msg "✅ 以下 **{项目名}** 未完成的待办项，请负责人及时更新

1. {Todo描述}，截止日期:{DDL}，薯名A(张三)
2. {Todo描述}，截止日期:无，<薯名B>

[相关文档链接]({URL})" --project "{项目名}"
```

规则：DDL 无则写"无"；正文已 @ 的人不传 mentionList。

---

## 场景2：查看例会文档更新情况

**⚠️ 每次必须重新拉取，禁止用记忆中的旧数据。**

**Step 1：执行通用前置步骤（见 api.md）**

**Step 2：找最新周会文档**

访问 `redocUrl`，在左侧目录找周会相关目录（如"测试周会"、"开发周会"），定位最新一期。

**Step 3：读取进展管理表格**

识别"进展"列未更新的行（空值/空格/占位符如"TBD"/"待补充"）。

**Step 4：输出格式（严格按此格式）**

```
PMO BP发现 @薯名A(张三) @薯名B(李四) 还没更新[例会文档]({URL})呢🙂，请记得会前更新好哦～
```

格式规则：
- `@{薯名}({真名})` 格式，多人空格分隔
- 文档链接用 `[例会文档](URL)` 可点击格式
- 薯名和真名都必须显示

**Step 5：发送通知（用户要求时）**

```bash
pmo send msg "{Step 4 输出内容}" --project "{项目名}"
# 或指定 chatId
pmo send msg "{内容}" --chat-id "{hiGroupId}"
```
