WHAT & HOW

怎么用？一句话的事

Skill 支持四类能力，覆盖从查告警到看规则的完整操作链路。每个场景都是用户真实对话动线。

1

查我收到的告警

"帮我看看我最近 10 分钟收到了哪些告警"

对话"昨天 base.obs 有哪些 P0 告警？"
→
能力event list — 按产品线 + 时间范围查事件列表
→
返回告警名称、级别、触发时间、持续时长、是否已认领
--apps --start --end --receive-users --rule-id
2

查某条告警的详情

"这条告警影响了哪些机器？触发条件是什么？"

对话"帮我看看 event_id=171238413 的详情"
→
能力event get — 按 event_id 查单条事件完整信息
→
返回告警级别、触发/恢复时间、受影响机器列表、采样值、规则配置链接
event_id --show-link
3

查某服务下有哪些告警规则

"帮我看看 xrayaiagent 这个服务配了哪些告警规则"

对话"xrayaiagent 有哪些告警规则？"
→
能力rule list — 按 app/prdLine/bizLine 搜索全部规则（PQL + 服务告警）
→
返回规则 ID、名称、类型（PQL/服务）、启用状态
--app --prdLine --bizLine --type
4

查某条规则的完整配置

"这条 CPU 告警的 PromQL 是什么？触发条件怎么配的？"

对话"帮我查 rule_id=1234 的完整配置"
→
能力rule get — 按 rule_id 查规则配置，自动识别 PQL / 服务告警
→
返回触发条件、PromQL 表达式、通知对象、启用状态
rule_id --type
CASES

真实使用案例

从"查告警"到"操作告警"，全在对话框里完成。

✋ 一句话批量认领

实时任务上线期间，手机一键认领告警

同学在做实时任务迭代上线，持续收到多条告警通知。不用开电脑、不用进 XRay 页面，打开 Hi 个人助理说一句「帮我认领最近 10 分钟的告警」，批量认领一步到位。

"能在手机上对话检索到自己的报警列表"
"帮我认领下我最近 2h 的告警"
用户原声

✅ 验证了移动端可用性  |  💡 用户核心诉求：「最需要的是，和 agent 说给我认领最近 xx 时间的告警」

🔇 认领 + 静默联动

认领后一键静默，告别重复告警轰炸

认领告警后，通常还需要设置静默规则，避免同一告警反复通知。现在只需一句话：「帮我认领并静默最近 2 小时的告警」——认领 + 静默联动操作，减少重复步骤。

"如果支持认领并静默更好"
两种认领粒度

① 按人：「把我收到的告警都认领了」  ② 按服务：「帮我把 xx 服务下的告警都认领了」
